# wavy

TurboWarp のペンレイヤーを、2次元パーリンノイズのディスプレイスメントマップで歪ませるカスタム拡張機能です。

## 読み込み方

1. TurboWarp で「拡張機能を追加」→「カスタム拡張機能」を開きます。
2. `wavy.js` をファイルとして選ぶか、内容を「テキスト」タブへ貼り付けます。
3. **「サンドボックスなしで実行」**を有効にして読み込みます。
4. 通常の「ペン」拡張機能も追加します。

ローカルサーバーから読み込む場合は、このフォルダーで次を実行します。

```sh
python3 -m http.server 8000
```

その後、カスタム拡張機能のURLに `http://localhost:8000/wavy.js` を指定します。

## ブロック

### `set noise scale (50) strength (12) offset x (0) y (0) seed (0)`

- `scale`: 波の大きさです。大きいほど、ゆるやかで大きな波になります。
- `strength`: 最大変位量です（ステージ座標のピクセル単位）。負数にすると歪みの向きが反転します。
- `offset x`, `offset y`: ノイズ空間を移動します。少しずつ変えてから `wavy` を実行すると、波が流れるように変化します。
- `seed`: 同じ値なら同じノイズになります。数字だけでなく文字列も使用できます。

### `wavy`

その時点のペン描画全体を、現在のノイズ設定で一度歪ませます。実行結果はペンレイヤーへ書き戻されるため、続けて実行すると歪みが累積します。「全部消す」ブロックを使うと通常どおり消去できます。

## 使用例

```text
全部消す
ペンを下ろす
100 回繰り返す
  4 歩動かす
  3 度回す
set noise scale (55) strength (16) offset x (0) y (0) seed (ocean)
wavy
```

## 注意

- ペンレイヤーを直接扱うため、TurboWarp 専用かつ非サンドボックス拡張です。
- `wavy` は画面上の全ピクセルを処理します。高画質ペンで非常に高い倍率を使う場合は、1回の処理に時間がかかることがあります。
- ペン描画がまだ作られていない状態で `wavy` を実行した場合は何もしません。
